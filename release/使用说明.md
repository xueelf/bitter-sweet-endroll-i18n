# Bitter Sweet Endroll 多语言补丁

为《ビタースイートエンドロール ～Bitter Sweets／The End～》追加多语言支持，
目前已完成中文。补丁不改动任何原版文件，随时可以卸载还原。

## 放到哪里

把 `patch.bat` 和 `app.asar` 一起放进**游戏根目录**（与 `Data` 同级）。
资源目录固定为 `.\Data`，找不到就说明位置放错了。

## 安装

1. 完全退出游戏。
2. 双击 `patch.bat`，在菜单里按 `1`（按一下即可，不用回车）。
3. 启动游戏，在标题画面或游戏内「设置」中选择「中文」。

## 卸载（还原为原版）

1. 完全退出游戏。
2. 双击 `patch.bat`，在菜单里按 `2`。
3. 游戏即还原为原版。

## 菜单

```text
当前状态：

  游戏目录: <脚本所在目录>
  游戏版本: <游戏本体版本>
  补丁版本: <本补丁版本>
  安装状态: 未安装 / 已安装

1) 安装补丁
2) 卸载补丁（还原为原版）
3) 退出

>
```

按一下对应的数字键就执行，不需要回车。

## 说明

- 安装时会把原版 `app.asar` 备份为 `base.asar`，卸载时再还原，原版文件不会丢失。
- 安装时比对游戏版本，不一致只提示，不影响安装。
- 补丁内置 Noto Serif SC 字体（SIL OFL 1.1，来源 [notofonts/noto-cjk](https://github.com/notofonts/noto-cjk)），统一替换游戏字体，许可文本随补丁一起分发。
- 游戏更新后需要重新安装本补丁。
- 命令行用法（可选，供脚本调用）：

  ```text
  patch.bat install
  patch.bat uninstall
  ```
