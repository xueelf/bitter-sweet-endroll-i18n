# bitter-sweet-endroll-i18n

游戏《ビタースイートエンドロール ～Bitter Sweets／The End～》的非官方多语言补丁，安装后可为游戏加入一套本地化框架：语言与译文存放在独立的词条文件里，可以自由添加、修改任意语言的翻译文本。

目前已完成中文，安装后可在游戏内切换语言，界面、剧情与全部台词都会随之切换。

友情提示，由于文本全由 AI 进行翻译，因此部分台词会出现特别生草的内容（

最新版下载：[Releases](https://github.com/xueelf/bitter-sweet-endroll-i18n/releases/latest)

## 使用方式

1. 完全退出游戏。
2. 把下载到的 `patch.bat` 和 `app.asar` 放进游戏根目录（与 `Data` 同级）。
3. 双击 `patch.bat`，按 `1` 安装。启动游戏后，在标题画面或游戏内「设置」中选择「中文」。

卸载：双击 `patch.bat`，按 `2`，游戏即恢复原版。详细步骤见 [`release/使用说明.md`](./release/使用说明.md)。

## 翻译步骤

译文放在 `locales/<语言代码>/` 下，路径与游戏原文件一一对应。每条词条的「键」是游戏里的日文原文，「值」是译文。还没翻译的条目标记为 `null`，游戏里会显示原文。

```json
{
  "設定": "设置",
  "終了": null
}
```

同步与构建：

```bash
bun install

# 重新扫描游戏文件里的文本，同步进词条文件：
# 游戏新增的文本会补进来（待翻译），删掉的会移除，已有的译文原样保留
bun run extract -- --game "<解包目录>"

# 构建补丁（需要游戏本体）
bun run build -- --game "<游戏根目录或 Data 目录>"
```

添加一种语言：

1. 建 `locales/<语言代码>/`（文件夹名就是语言代码，如 `zh`），按同样的结构放词条文件。
2. 写一个 `index.js` 声明这门语言的基本信息：

   ```js
   export default {
     // 语言在「设置」列表里显示的名字
     label: '中文',
     messages: {
       // 「设置」里语言行的标题
       language: '语言',
       // 启动画面上的文字
       startup: '启动中…',
     },
   };
   ```

3. 重新构建，游戏「设置」里的语言列表会自动多出这一项。
