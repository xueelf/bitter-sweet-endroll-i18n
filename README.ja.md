# Bitter Sweet Endroll i18n

ゲーム [ビタースイートエンドロール ～Bitter Sweets／The End～](https://www.dlsite.com/aix/work/=/product_id/RJ01685413.html) の非公式多言語パッチで、プログラムの「設定」画面内に多言語メニューを追加し、ゲーム内でいつでも任意の言語に切り替えられます。

現在は中国語訳を提供しており、AI モデル DeepSeek V4.1 Flash Max による校正済みです。なお、テキストの一部はすべて AI によって処理されているため、一部のセリフには特に不自然な内容が現れます。

他の言語で読む：[English](./README.md) | [中文](./README.zh.md) | 日本語

## ダウンロード

[GitHub Releases](https://github.com/xueelf/bitter-sweet-endroll-i18n/releases/latest) からインストーラーをダウンロードしてください：

- `BitterSweetEndroll-i18n.exe`

## 使い方

1. ゲームを完全に終了します。
2. `BitterSweetEndroll-i18n.exe` をゲームのルート（`Data` フォルダと同じ場所）に置きます。
3. exe をダブルクリックし、番号を選択します：

```text
1) インストール/更新
2) アンインストール
3) 終了
```

インストール時にゲーム原本の `Data/resources/app.asar` を `Data/resources/base.asar` としてバックアップします。アンインストールすると原本に戻し、バックアップを削除します。

プログラムの UI 言語は Windows のシステム言語に従い、例えばシステムが中国語の場合は中国語を表示し、システムが日本語の場合は日本語を表示します。システム言語に対応する多言語テキストがない場合（locales フォルダ内に翻訳テキストが存在しない場合）、デフォルトで日本語を表示します。

## 開発

パッチは Bun と .NET 8 SDK でビルドします：

```bash
# ゲームテキストを走査し、ロケールファイルに同期する
bun run extract -- --game "<展開済みディレクトリ>"
# パッチをビルド（ゲーム本体が必要）
bun run build -- --game "<ゲームルートまたは Data ディレクトリ>"
# インストーラーをビルド（.NET 8 SDK が必要）
bun run installer
```

翻訳文は `locales/<言語コード>/` に配置し、パスはゲーム原本のファイルと一対一に対応します。未翻訳の項目は `null` としてマークし、ゲーム内では原文が表示されます：

```json
{
  "設定": "设置",
  "終了": null
}
```

言語の基本情報は `locales/<言語コード>/index.js` 内で宣言できます：

```js
export default {
  // 「設定」リストに表示される言語名
  label: '日本語',
  messages: {
    // 「設定」画面の言語メニュー行のタイトル
    language: '言語',
    // 起動画面のテキスト
    startup: '起動中…',
  },
};
```
